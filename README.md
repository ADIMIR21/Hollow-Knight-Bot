# Hollow Knight AI Bot 🤖

**Hollow Knight AI Bot** — проект по обучению искусственного интеллекта (Deep Reinforcement Learning) сражению с боссами в игре **Hollow Knight** с использованием алгоритма **PPO** (Proximal Policy Optimization).

## Архитектура

Проект состоит из двух основных компонентов:

### 1. C# Mod для Hollow Knight (`Mod/HK_AI_Mod/`)

Мод для Hollow Knight, экспортирующий телеметрию игры в JSON-файл (`%TEMP%/hk_ai_data.json`, атомарная запись):

- **Позиция игрока** (X, Y) и скорость
- **HP игрока**, запас душ (MP)
- **HP босса** (автоматически определяется как объект с наибольшим HP > 20), позиция и скорость босса
- **Флаги состояний**: grounded, атака, рывок, прыжок, падение, отдача, `boss_is_attacking`, `near_hazard`, `was_hit`
- **Монотонные счётчики**: `hit_counter` (полученные удары) и `boss_damage_total` (суммарный урон боссу)

Мод 2.2 также поддерживает **быстрый рестарт**: Python кладёт `restart` в `%TEMP%/hk_ai_cmd.txt`, и мод мгновенно перезагружает сцену боя через `BeginSceneTransition`. Целевая сцена (босс) читается из `%TEMP%/hk_ai_boss.txt`; по умолчанию — пантеонная версия `GG_False_Knight`. Python записывает этот конфиг при старте (см. переменную `HK_BOSS_SCENE`). Если установленный мод не поддерживает быстрый рестарт, среда автоматически откатывается на старый макрос геймпада.

### 2. Python-фреймворк для RL

| Файл | Назначение |
|------|------------|
| `ai_controller.py` | Эмуляция геймпада Xbox 360 через `vgamepad` (16 дискретных действий), команды быстрого рестарта |
| `screen_capture.py` | Захват экрана игры через `mss` + авто-наведение на окно Hollow Knight |
| `ai_environment.py` | Среда: объединяет видеопоток и телеметрию |
| `hk_gym.py` | **Gymnasium-среда** — ядро RL: пространство наблюдений, награды, логика эпизодов |
| `train.py` | **Обучение PPO** через Stable-Baselines3 с чекпоинтами |
| `ai_receiver.py` | Отладчик телеметрии в реальном времени |

Для работы фреймворка в игру должен быть загружен мод!  
Рекомендуемая версия игры - V1.5.78.1183.  
Так же рекомендуем использовать Scarab.

## Пространство наблюдений

- Вектор из **25 числовых параметров**: HP, душа, HP босса, позиции игрока и босса, расстояние и направление до босса, скорости, флаги состояний (grounded, атака, рывок, прыжок, падение, отдача, `boss_is_attacking`, `near_hazard`)
- **Frame stack**: стек из 4 последних векторов → `100` признаков на вход политики (задаётся `HK_FRAME_STACK`)
- **Frame skip**: действие удерживается 4 шага игры (~64 мс) между решениями (задаётся `HK_FRAME_SKIP`)
- Наблюдения нормализуются через `VecNormalize` (нормализация награды отключена, чтобы не клипать сигналы победы/смерти)

## Функция награды

Potential-based shaping: `r = Φ(s') − Φ(s)`, где `Φ = 15 · (урон, нанесённый боссу) − 10 · (потерянное HP игрока)`.

- **+1000** за победу над боссом (терминальная)
- **-200** за смерть игрока (терминальная)
- **-0.05** за каждый шаг (штраф за промедление)

Такой шейпинг математически не меняет оптимальную политику и не даёт агенту «фармить» вспомогательные бонусы (спам прыжков/движения), которые были в старой функции награды.

## Установка и запуск

### Требования

- **Hollow Knight** (Steam-версия)
- **Modding API** для Hollow Knight (установлен)
- **Python 3.10+**
- **.NET Framework 4.7.2** (для сборки мода)

### Установка Python-зависимостей

```bash
pip install -r requirements.txt
```

### Сборка и установка мода

1. Открой `Mod/HK_AI_Mod/HK_AI_Mod.csproj` в Visual Studio / Rider
2. Собери проект (Build)
3. Скопируй `HK_AI_Mod.dll` в папку модов Hollow Knight (`hollow_knight/hollow_knight_Data/Managed/Mods/`)

### Запуск обучения

```bash
python train.py
```

- Модель автоматически загрузит последний чекпоинт (`models/ppo_hk/hk_model_final.zip`), если он существует
- Если сохранённый `vecnormalize.pkl` от другого пространства наблюдений — он будет отброшен, нормализация начнётся заново
- Чекпоинты сохраняются каждые 20 000 шагов в `models/ppo_hk/`
- Авто-рестарт боя включён по умолчанию (быстрый через мод, иначе макрос)
- Во время обучения можно управлять через консоль:
  - `r` — включить авто-рестарт боя после смерти/победы
  - `s` — выключить авто-рестарт
  - `q` — выход

Переменные окружения:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `HK_BOSS_SCENE` | `GG_False_Knight` | Сцена, в которую мод перезагружается при быстром рестарте (можно указать любого пантеонного босса: `GG_Hornet_1`, `GG_Gruz_Mother` и т.д.) |
| `HK_FRAME_SKIP` | `4` | Сколько шагов игры держится действие |
| `HK_FRAME_STACK` | `4` | Сколько последних наблюдений в стеке |

### Отладка телеметрии

```bash
python ai_receiver.py
```

## Параметры обучения (PPO)

| Параметр | Значение |
|----------|----------|
| Алгоритм | PPO (Stable-Baselines3) |
| Политика | MlpPolicy, net_arch [256, 256] |
| Learning rate | 3e-4 с линейным затуханием |
| n_steps | 2048 |
| batch_size | 128 |
| n_epochs | 10 |
| ent_coef | 0.01 |
| clip_range | 0.2 |
| gamma | 0.99 |
| Нормализация наблюдений | VecNormalize, clip_obs 10 |
| Нормализация награды | выключена |
| Всего шагов | 2 000 000 |
